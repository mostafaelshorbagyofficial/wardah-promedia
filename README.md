# Wardah Egypt × ProMedia
**Brand Development, Experience & Growth Strategy | Food & Beverage Marketing Portfolio**

Production-ready, fully responsive, bilingual (Arabic & English) presentation website built for **ProMedia** showcasing its Food & Beverage clients and presenting the comprehensive marketing & growth proposal for **Wardah Egypt — Restaurant & Cafe**.

## Features
- **Bilingual & RTL/LTR Native**: Instant dynamic switching between Arabic and English with proper typographic hierarchy.
- **Direct In-Page Video Showreel**: High-performance local video player featuring ProMedia production work without modal intermediaries.
- **Verified F&B Portfolio**: Interactive showcase of 10 verified restaurant and cafe clients with metrics and live destinations.
- **Wardah Brand Strategy & Growth Vision**: 15 complete sections covering Experience Development, GCC visitor acquisition, creative launch campaigns, and 90-day roadmap.
- **Curated Influencer Directory**: 42 candidates with priority placement for El Zuzzat, platform filters, and user-provided reference data.
- **100% Strict Local Assets**: Zero external CDN imports or remote asset dependencies.

## Tech Stack
- React 19 + TypeScript
- Vite 6
- Tailwind CSS
- Lucide Icons (Inline optimized)

## Getting Started
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
